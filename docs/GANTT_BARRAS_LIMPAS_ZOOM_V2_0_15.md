# Atlas V2.0.15 — barras limpas e zoom efetivo no Gantt

## Ajustes

- Remove qualquer texto, percentual, quantidade ou período de dentro das barras.
- A barra passa a usar somente a cor correspondente ao status.
- Mantém quantidade realizada e período exclusivamente no painel esquerdo.
- Refaz o cálculo do zoom horizontal para que cada clique altere imediatamente a largura da linha do tempo.
- Zoom entre 1× e 5×, em passos de 0,25×.
- O botão **Ajustar** retorna para 1×.
- O painel esquerdo mantém largura e tamanho dos textos inalterados.
- O scroll horizontal e vertical é preservado ao trocar o zoom.

Nenhuma alteração de banco de dados é necessária.
