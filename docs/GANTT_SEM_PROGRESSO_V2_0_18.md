# Atlas V2.0.18 — Gantt sem Progresso/Realizado

O Gantt volta a exibir apenas a estrutura do cronograma:

- projeto e subelementos;
- período;
- escala em dias, semanas ou meses;
- barras sólidas coloridas pelo status;
- zoom horizontal independente da área esquerda.

As colunas Progresso e Realizado foram removidas da visualização. Os campos Realizado criados na V2.0.17 foram apenas desativados no Supabase para preservar qualquer dado existente.
